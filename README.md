# Archivarius Web

Система управления документами и файлами с расширенными возможностями поиска и организации.

## 🚀 Быстрый старт

### Простая установка (рекомендуется)

**Следуйте пошаговой инструкции:** [INSTALL.md](INSTALL.md)

Это самая простая инструкция для быстрого развертывания на новом сервере.

### Настройка конфигурации

**Подробное описание всех параметров:** [CONFIG.md](CONFIG.md)

Узнайте, как правильно настроить конфигурационный файл и что в нем менять.

### Автоматическая установка (скрипт)

```bash
# Клонируйте репозиторий
git clone https://github.com/your-repo/archivarius_web.git
cd archivarius_web

# Запустите скрипт установки
chmod +x deploy.sh
sudo ./deploy.sh
```

Скрипт автоматически установит все зависимости и настроит приложение. Следуйте инструкциям на экране.

### Подробная документация

Для детального разбора всех аспектов установки см. [DEPLOYMENT.md](DEPLOYMENT.md)

## Требования

- **PostgreSQL 12+**
- **PHP 8.1+** с расширениями (pgsql, mysql, imagick, mbstring, zip, bcmath, intl, xml)
- **Nginx**
- **Manticore Search**
- **Node.js 16+** и **npm**
- **Composer**

Полный список требований и инструкции по установке см. в [DEPLOYMENT.md](DEPLOYMENT.md)

## Основные возможности

- 📁 Управление файлами и документами
- 🔍 Полнотекстовый поиск (Manticore Search)
- 👥 Управление пользователями и правами доступа
- 📊 Атрибуты и метаданные файлов
- 📦 Импорт/экспорт данных
- 🌐 Многоязычный интерфейс
- 🔐 Безопасная аутентификация

## Конфигурация

1. Скопируйте пример конфигурации:
```bash
cp config/archivarius_web_config.php.sample config/archivarius_web_config.php
```

2. Отредактируйте `config/archivarius_web_config.php`:
   - Настройте подключение к базе данных
   - Укажите URL сайта
   - Настройте email для отправки писем

## Разработка

### Установка зависимостей

```bash
# PHP зависимости
composer install

# Фронтенд зависимости
cd main && npm install && cd ..
cd auth && npm install && cd ..
```

### Компиляция ассетов

```bash
# Основное приложение
cd main
npm run compile:main.css
npm run compile:main.js
npm run update_asset_version

# Страница авторизации
cd ../auth
npm run compile:main.css
npm run compile:main.js
npm run update_asset_version
```

### Режим разработки (watch)

```bash
cd main && npm run watch &
cd auth && npm run watch &
```

