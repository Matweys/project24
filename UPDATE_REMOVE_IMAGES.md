# Инструкция по удалению фоновых изображений на сервере

## Шаги для выполнения на сервере:

### 1. Забрать обновления из GitHub
```bash
cd /path/to/project24
git pull origin main
```

### 2. Выполнить SQL скрипт для очистки настроек изображений
```bash
# Для PostgreSQL:
psql -U ваш_пользователь -d ваша_база_данных -f db/clear_images.sql

# Или через psql интерактивно:
psql -U ваш_пользователь -d ваша_база_данных
\i db/clear_images.sql
\q
```

### 3. Перекомпилировать CSS из SCSS
```bash
cd main
npm run compile:main.css
```

### 4. (Опционально) Обновить версию ассетов
```bash
npm run update_asset_version
```

### 5. Проверить результат
После выполнения всех шагов обновите страницу в браузере (Ctrl+F5 для полной перезагрузки с очисткой кеша).

## Что было изменено:

- Изображение логотипа теперь скрывается, если `header_logo_url` пустой
- Создан SQL скрипт для очистки настроек изображений из базы данных
